# 웹기획자 개인 포트폴리오 사이트

순수 HTML / CSS / JavaScript로만 동작하는 정적 사이트입니다. 빌드 도구·서버·DB가 필요 없습니다.

## 1. 실행 방법

`index.html`을 브라우저로 열면 바로 동작합니다. (더블클릭 또는 브라우저에 드래그)

배포할 때는 아래 폴더 전체를 그대로 올리면 됩니다. GitHub Pages, Netlify, Vercel, 웹호스팅 모두 추가 설정 없이 동작합니다.

## 2. 파일 구조

```
portfolio/
├── index.html              목록 페이지 (소개 + 카드형 5개 + 텍스트형 5개)
├── project-detail.html     상세 페이지 (상위 5개 공용, ?id= 로 내용이 바뀜)
├── data.js                 ★ 콘텐츠 데이터 — 여기만 수정하면 됩니다
├── README.md
└── assets/
    ├── css/style.css       전체 스타일 (색상은 파일 상단 :root 변수에서 변경)
    └── js/
        ├── list.js         목록 페이지 렌더링
        └── detail.js       상세 페이지 렌더링
```

상세 페이지는 프로젝트마다 HTML 파일을 만들지 않고 `project-detail.html` 하나를 공용으로 씁니다. 카드에서 `project-detail.html?id=lms-renewal` 형태로 이동하면 `data.js`에서 해당 `id`를 찾아 화면을 그립니다. 프로젝트를 추가·삭제해도 HTML 파일을 늘리거나 지울 필요가 없습니다.

## 3. 내용 교체 방법 (data.js)

`data.js` 하나만 수정하면 사이트 전체 내용이 바뀝니다. HTML·CSS·JS는 건드리지 않아도 됩니다.

### PROFILE — 상단 소개

이름, 직함, 한 줄 포지셔닝, 소개 문단, 요약 지표, 이메일, 외부 링크를 담습니다. 요약 지표(`highlights`)나 외부 링크(`links`)가 필요 없으면 `[]`로 비워 두면 해당 영역이 화면에서 사라집니다.

### FEATURED_PROJECTS — 상위 5개 (카드형 + 상세 페이지)

| 항목 | 필수 | 설명 |
|---|---|---|
| `id` | 필수 | 상세 페이지 주소에 쓰이는 고유값. 영문·숫자·하이픈만 쓰고 중복되지 않게 합니다. |
| `name` | 필수 | 프로젝트명 |
| `thumbnail` | 필수 | 목록 카드의 대표 이미지 URL |
| `summary` | 필수 | 한 줄 소개 |
| `role` | 필수 | 담당 역할 |
| `screens` | 필수 | 사용 화면 이미지 URL 배열. 1개든 5개든 넣는 만큼 세로로 나열됩니다. |
| `siteUrl` | 필수 | 실제 사이트 링크 (새 탭으로 열림) |
| `period` | 선택 | 진행 기간. 지우면 표시되지 않습니다. |
| `tags` | 선택 | 역할 키워드 배열. 지우면 표시되지 않습니다. |

### LINK_PROJECTS — 하위 5개 (텍스트 + 바로가기)

`name`(프로젝트명)과 `siteUrl`(외부 사이트 링크)만 있으면 됩니다. `note`는 선택 항목으로, 프로젝트명 아래 한 줄 설명으로 표시되며 지우면 나오지 않습니다. 이 그룹에는 상세 페이지가 없고 클릭하면 바로 외부 사이트로 이동합니다.

### 노출 순서

검색·필터·정렬 기능은 없습니다. **배열에 적은 순서가 곧 화면 노출 순서**입니다. 순서를 바꾸려면 `data.js` 배열 안에서 항목의 위치를 위아래로 옮기면 됩니다.

### 개수 변경

5개 / 5개는 고정된 제약이 아닙니다. 배열에 항목을 추가하거나 빼면 카드 그리드와 리스트가 자동으로 맞춰집니다. 카드 개수 표시(`5건`)도 자동으로 갱신됩니다.

## 4. 이미지

현재는 `picsum.photos` 플레이스홀더 이미지가 들어가 있습니다. 실제 이미지로 바꿀 때는 두 가지 방법이 있습니다.

프로젝트 폴더에 `assets/images/` 를 만들어 파일을 넣고 `thumbnail: 'assets/images/lms-thumb.png'` 처럼 상대 경로를 쓰거나, 이미 웹에 올라가 있는 이미지의 전체 주소(`https://...`)를 그대로 쓰면 됩니다.

대표 이미지는 가로:세로 16:10 비율에 맞춰 잘리므로 가로로 넉넉한 이미지(권장 1200×750 이상)를 쓰는 편이 좋습니다. 사용 화면 스크린샷은 원본 비율 그대로 표시됩니다.

## 5. 디자인 변경

`assets/css/style.css` 맨 위 `:root` 블록의 변수만 바꾸면 전체 색상·모서리 둥글기·최대 너비가 한 번에 바뀝니다. 포인트 컬러는 `--accent` 한 개만 쓰고 있어, 이 값 하나만 바꿔도 사이트 분위기를 바꿀 수 있습니다.

시스템이 다크 모드일 때를 위한 색상도 함께 정의되어 있습니다. 항상 밝은 화면으로만 보이게 하려면 `index.html`과 `project-detail.html`의 `<html lang="ko">`를 `<html lang="ko" data-theme="light">`로 바꾸면 됩니다.

## 6. 의도적으로 넣지 않은 기능

기획서의 범위 정의에 따라 아래 기능은 포함하지 않았습니다.

로그인·회원가입·결제, 문의 폼(연락은 이메일 링크와 외부 링크로만 제공), 관리자/일반 사용자 구분, 프로젝트 검색·필터·정렬, 하위 5개 프로젝트의 상세 페이지.
